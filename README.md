# Candy Crush Game

A simple Candy Crush game built using HTML, CSS, and JavaScript.

## Features
- Drag and drop candies
- Match 3 or more candies
- Score tracking
- Responsive game board

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository
2. Open candycrush.html in your browser
